# Style System

Use this file when styling a generated page.

## Defaults

- Canvas: 16:9 stage inside a responsive page.
- Palette: off-white background, near-black text, one strong accent, one warm support color, one cool support color.
- Typography: system UI stack. Large hero text, compact card labels, no negative letter spacing.
- Motion: subtle reveal and flow movement only. Avoid motion that distracts from reading.

## Layout

- Use a visible hierarchy: hero, flow, evidence, CTA.
- Alternate dense and quiet areas.
- Keep diagrams inside stable aspect-ratio containers.
- Use rounded corners sparingly; cards should be 8-16px radius depending on visual density.

## Recruiting Or Portfolio Use

- Put proof before implementation details.
- Use screenshots or metrics only with labels explaining why they matter.
- Keep the first viewport understandable in under 10 seconds.
- Prefer "what this proves" wording over "what I did" wording.
